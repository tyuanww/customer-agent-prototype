# Tutorial：管理员导入 MENOKIN FAQ 并发布

本页带你用**当前 main 打的 UNSIGNED** 走完一条可观察的内容链：

`打开工作台 → 管理员登录 → 内容管理选 xlsx → 发布 → 查询「面膜紫适用人群」拿到新 Top 3`

这不是第一次运行浮窗。狐狸 / 查询 / 复制先看 [第一次运行](tutorial-first-run.md)。打包配置看 [macOS 打包态远端](how-to-macos-packaged-product-remote.md)。

xlsx 原文、订单、图片不进 Git。文件放在仓外（例如本机 `Desktop/customer-agent- FAQ/`）。

## 你需要

1. 当前 main **0.3.22** 打的 UNSIGNED `.app`（`pnpm package:mac:local`）。更早的包没有五项工作台、停手文案校验、顶栏收口和两行发布回执。
2. `~/Library/Application Support/客服话术浮窗 Demo/synthetic-stack.json` 指向 `agent-auth` / `agent-pass`。
3. 本机合成栈和命名隧道健康：`https://agent-auth.jianghua.site/health` 为 200。
4. **管理员**会话（`synthetic_owner`）。话术师可以导入、可以预览，但发布禁用，原因写「一期发布仅管理员。话术师可导入产品或活动草稿，发布需管理员操作。」——不是 HTTP 403。
5. 一份仓外 FAQ 表，第一张表有中文表头（快捷短语 / 产品话术 / 业务填写问题 / 客满话术 任一列即可）。

## 步骤

1. 关掉旧的 `.app`，打开这次打的 UNSIGNED。
2. 点狐狸 → 查询胶囊上的工作台图标。登录选 **账号**，用管理员绑定（合成栈是 `synthetic_owner`）。
3. 侧栏点 **内容管理**。对照屏幕核对：

   ```
   顶栏：内容管理  [已接入]  导入与发布走产品会话
   同一行： [取消未完成导入]  [发布]
   下面： ▸ 待开发 · 内容导入
   ```

   - 徽章只有三态：`未接入`（无会话）、`正在确认会话`（首次读取会话还没返回）、`已接入`（已登录，含话术师 / 坐席）。徽章说的是会话接没接上，不是你有没有发布权。
   - 「取消未完成导入」和「发布」必须在同一行，取消在左、发布在右。没有会话时两个都禁用，且**不会**写假发布。
   - 折叠 summary 四态：没选文件时 `待开发 · 内容导入`；读取中 `待开发 · 正在读取 {文件名}`；读失败 `待开发 · 未进入待发布 · {文件名}`；读好了 `待开发 · {文件名} · 待发布 {n} 行`。
4. **先点开** **待开发 · 内容导入**，再选仓外 xlsx（选文件控件在折叠体内）。读文件后折叠体会保持展开。预览大约一百行量级（空白行会跳过）。下面会显示识别到的归属话术库（产品 / 活动 / 售前 / 售后）；不对就用下拉改过来，选错库不会报错但会传错区。售后 / 过敏 / 赔付一期只能管理员发。
5. 点 **发布**。导入会先 `validating`，校验通过后 `staged`，再 `POST /v1/content/publish`。成功主句 `已发布 rel_N · 姓名`；有 summary 才画第二行四库 delta。发布钮保持禁用，直到清除预览或重选文件。发布进行中「取消未完成导入」仍可用。失败时屏幕写中文原因和下一步，不要对着英文合同码发呆，也不要出现 delta 行。
6. 成功后记下 `releaseId`。关掉工作台，回到查询胶囊。
7. 搜 **面膜紫适用人群**。Top 3 必须来自刚发布的目录，不是仓内合成样例。卡片没有匹配分。复制只显示「已复制」。

## 失败时

| 你看到 | 原因 |
| --- | --- |
| 文件和当前登记的来源对不上 | 导入会先把这份表登记为新 snapshot；若仍失败，确认选的是要发的那份表 |
| 你自己的上一份草稿还在队列里（还没发布） | 同一账号的上一份还没发完就点了下一份：先发布或点「取消未完成导入」，再导下一份 |
| 表里有内容和线上已有版本冲突 | 这不是在途问题。同一个 `script_id`（由域 + 场景 + 正文生成）已被线上发布成不同话术：改表后重新导入，重试或取消都没用 |
| 一期发布仅管理员。话术师可导入产品或活动草稿，发布需管理员操作。 | 话术师点了发布；换管理员 |
| 未接入 | 没登录，或打包态没读到 `synthetic-stack.json`。屏幕上发布/取消的禁用原因写「当前没有产品会话，无法发布」 |
| 表格式或花括号不合法 | 按模板改表后重新导入 |
| Top 3 仍是旧稿 | 查询前会 `refreshAnnounce`；若仍旧，确认发布成功且搜的是新场景原文 |
