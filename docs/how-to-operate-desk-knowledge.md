# 如何准备本机话术草稿

在工作台的 **内容库 → 本机草稿** 中，运营可以手动填写问答，或导入 CSV、Excel。草稿只保存在当前电脑，查询窗口不会读取这里的内容。

字段和通道见[本机草稿参考](reference-desk-knowledge.md)，与正式内容的关系见[内容库与草稿的边界](explanation-desk-knowledge.md)。

## 步骤

1. 用有编辑资格的账号登录，打开 **内容库 → 本机草稿**。
2. 选择 **全店**、**售前客服** 或 **售后客服**，查看对应话术。
3. 点 **添加话术**，选择 CSV 或 Excel。预览会列出识别的条目、图片以及未导入的内容；核对后再确认导入。
4. 没有文件时，点 **没有文档？手动填写一条**，填写问题、答案、分类和本机有效期，再保存。
5. 需要团队使用时，通过 **上传团队资料** 进入资料审核，使用对应的正式模板上传、审核和发布。现有本机草稿不会自动变成服务器待审资料。

## 怎样确认

- 导入成功后显示“已导入 N 条，状态是未生效。”，切换到对应人设可查看原文和图片。
- 修改本机有效期只改变本机列表，不代表内容已经对团队发布。
- 发布后的内容从 **内容库 → 已发布** 和查询窗口核对；复制成功只表示已写入剪贴板。

## 导入失败时

检查预览里的具体原因。Excel 支持 PNG、JPEG 行内图片，不能归属到可导入话术的图片会阻止导入；背景图等未导入内容会单独列出。不要把本机导入成功当作正式模板校验通过。

权限或登录失效时，先恢复登录和授权；写入失败时保留原文件，按页面提示重试。不要删除本机数据文件来处理读取故障。
