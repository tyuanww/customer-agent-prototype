## 可见验收

- [ ] **SOP。** 同一流程打开两笔。直接用短编号识别、暂放并恢复指定一笔。改名后标题、书签与恢复菜单仍指向同一笔。取消结束保留进度，确认只结束所选一笔。
- [ ] **查询。** 在 360×240 窗口辨认已选店铺和附加条件。快捷键提示与实际行为一致，风险说明先于正文和复制。分别走无命中、范围到期和读取失败，核对「修改问句」「刷新范围」或「重试」对应的状态。无命中保留原问句并等待手动提交。
- [ ] **主管。** 首页看到具体批次的下一步。用鼠标和键盘各选择一行，核对打开的是该行对应的已授权批次。选中失败可重试，撤权后收回行内操作。
- [ ] **飞书群联系。** 无可用结果时显示人工进入客服飞书群联系值班人员的说明。保留修改问句和可用的手动找流程。确认本动作不触发查询、打开外部应用或提交客户资料。
- **后续范围。** 若启用转交回执，再确定由谁在群内接手，以及记录如何关联本次求助。取得受控回执后，验证待接手、已接手、失败和重试。

当前帮助能力只复制合成联系方式或打开联系入口。其回执记录坐席动作，未提供接收人或接手状态。 [现有帮助命令](../../apps/desktop/src/main/product-search.ts) · [帮助回执类型](../../apps/desktop/src/shared/product-help.ts)

每个代码 PR 运行定向回归与相关构建检查。界面变化用合成输入核对实际 Electron 交互。同一候选的 macOS 和 Windows 验收及未测范围分别记录。复制只表示已复制。联系入口只表示打开联系渠道，接手以接收方回执为准。
