## 2. 每条需求对应的行为

| 用户要求 | 已确认行为与验收项 |
| --- | --- |
| 查询区、SOP 待办区、Top3 区 | 同一 Query 内纵向排列。查询首页只显示前两区；主动查询才出现 Top3。隐藏的旧结果不能由数字快捷键复制，F7 不能从隐藏入口新建流程。SOP 执行时同窗展示步骤页。 |
| 待办悬停显示叉号 | hover 与键盘 focus 都显示，粗指针常显；44px 命中位固定，不挤动文字。关闭按钮和恢复入口是同级控件。 |
| 叉号退出当前 SOP | 表示结束并清除对应进度，确认区明确说明影响；取消保留。返回搜索表示保留进度，两者区分。查询区使用行内确认，展开确认时重新测量原生窗口高度；步骤页沿用 AntD Modal。 |
| 查询区都可拖动 | 背景和区块留白可拖；输入、按钮、开关、链接、可选择正文、菜单、滚动条与缩放边保留自己的操作。背景单击无动作，狐狸仍保留原有点击收起。 |
| 点待办恢复上次 SOP 大小和步骤 | 恢复原任务，读取其最后手动尺寸与当前步骤。屏幕变小时临时钳制，不能将钳制后的值覆盖记忆尺寸。进入 waiting 任务不自动解除等待。 |
| 返回后窗口缩小 | 转到 query-home，隐藏 Top3，按查询区、待办和实际提示的总自然高度收缩。保留 query/results 数据，旧查询回包不能重新打开 Top3。 |
| 丝滑展开 | Main 管理同一原生窗口的起止与有界包络，renderer 只做裁切和内容淡入；不逐帧开放 bounds，不缩放文字。减少动态效果直接终态；反向操作和拖动会取消旧过渡。 |
| AntD 统一步骤页 | 继续使用真实 React + AntD Card、Button、Checkbox、Radio、Collapse/Modal。正文、步骤、话术、分支、等待、错误和清除确认保持同一语义色与尺寸规则。 |
| 每步可输出话术 | 每步的客户话术必须关联具体步骤及业务来源并审核。缺项保持待补齐，不能由渲染器生成。当前合成样例有缺项，不代表真实表已齐全。 |
| 默认隐藏话术 | 每次进入步骤默认折叠正文；展开不复制、不推进。单条可默认选中，多条先明确选中，快捷键不猜。 |
| 快捷键与复制后推进 | F6 和按钮走同一 Main 操作。普通步骤核实齐全才在复制成功后推进；F8 保留明确下一步。普通 Top3 的复制不推进 SOP。 |
| 所有设计在一个桌面端 | 唯一源码、构建、验收入口见第 7 节。画布是设计输入，不是平行桌面或第二份运行源码。 |

用户已明确选择多条独立待办，一次展开一条。Main 以独立任务标识与各自修订、历史、选择和等待管理；Overlay 按任务保留尺寸。新建与恢复分离，同名任务以短序号区分，不自动识别客户，不扩展跨设备持久化平台。

## 3. 展示状态与尺寸

| 展示态 | 可见内容 | 尺寸规则 |
| --- | --- | --- |
| query-home | 原查询胶囊、SOP 待办、必要提示 | 查询宽延续既有 600px，经屏幕钳制。高度按内容测量。画布约 208px 仅为单待办示例，不硬编码到运行时。 |
| query-results | 查询、待办、主动查询结果 | 整体测高包含三块，超过高度预算只滚动结果区，不挤掉查询与待办。 |
| sop | 当前步骤、折叠话术、必要判断、固定操作区 | 恢复上次手动 SOP 尺寸；初始沿用 580×620，正常最小 300×320，工作区不足时钳制。 |

普通查询宽 600，而现行 SOP 最大宽 580。因此“返回缩小”主要指高度按查询首页收缩，宽度回原查询宽度，不能承诺宽高都缩。沿用既有锚点；不新增横向侧栏。动画中间值不写回用户尺寸。

实施前大空白的机制是：QueryApp 返回只改 renderer 的 `sopView`，Main 因会话存活保留 `sopActive`，忽略测高并继续使用 `sopSize`；CSS 又按会话存在强制 100vh。本轮从展示所有权修复，不能靠清空结果或 CSS 掩盖。查询测高必须包含待办、关闭确认及错误提示，不能沿用只量搜索栏的 88px 特例。

过渡使用现有阶段协议。开始时停用旧视图交互，目标视图按目标宽度排版后测量，Main 应用屏内包络，renderer 执行裁切与淡入，匹配 viewEpoch 的末帧回执再收口到最终 bounds。180ms 结构与 120ms 内容只是画布候选，实现从既有动效真源选值。超时仅作异常恢复，不能用固定延时证明正常结束。

## 4. 话术输出矩阵

| 当前状态 | F6 / 点击复制成功 | 仍由坐席完成 |
| --- | --- | --- |
| 普通 action，核实齐全 | 复制并进入明确后继一步 | 后续步骤核实 |
| 普通 action，核实未齐 | 已复制，停在本步，明确提示仍待核实 | 确认材料与事实，不能由复制自动勾选 |
| decision | 已复制，停在判断步骤 | 点选真实分支；不自动猜分支 |
| waiting 会话状态 | 拒绝复制与推进 | 明确继续处理 |
| terminal | 复制后留在终点 | 确认结束，不自动清除进度 |
| 无可用话术 | 不生成正文，不开放伪复制 | 当前合成内部步骤可显式下一步；正式每步话术缺项进入业务审核 |
| 多条话术尚未选中 | 不复制 | 明确选择；直接点某条复制本身是明确选择 |
| 剪贴板失败、修订过期或内容不可用 | 不推进，不显示成功 | 按可见原因重试或受控重读 |

“已复制”继续只表示系统剪贴板写入成功，不表示发送、采纳、完成服务或解决问题。

实施前 `copyCurrent` 成功会递增 sessionId，renderer 再拿旧修订调用 next 会被拒绝。本轮改为在 Main 内完成一次有语义的同步操作：校验当前任务和话术、纯计算后继、写剪贴板、成功后一次提交内存状态并发布投影。结果区分 copied-advanced、copied-stayed、failed，不暴露 prepare/commit 多阶段给 renderer。

这不是剪贴板与内存的崩溃事务。未来正式网络推进不能与系统剪贴板原子提交，必须另按正式合同表达确认、重复请求与恢复，不能照搬当前内存保证。

快捷键沿用当前 F6/F8。输入法、输入编辑、修饰键、长按重复、菜单、确认框、等待和处理中均拦截；Mac 的真实 Fn 及系统快捷键需要目标机验证。按钮始终可用作明确入口。

## 5. 架构选择与失败路径

比较的候选是现有 SOP controller 拥有全部三态，以及现有 Overlay 拥有窗口展示、SOP controller 拥有业务状态。选择后者为设计基底。普通查询展示不依赖 SOP 域，不新增通用工作区 controller。

| 所有者 | 职责 |
| --- | --- |
| OverlayController | query-home/query-results/sop 展示态、viewEpoch、原生尺寸、手势、记忆与动画取消 |
| SopWindowController | 任务实例、业务修订、历史、核实、话术选择、等待及复制副作用 |
| 现有 Main 装配点 | 组合读取并发布一致快照；不缓存第二份可写业务状态 |
| shared | 三态判别联合、纯状态转换、严格 validator；不产生 I/O |
| preload / IPC | Query sender、role、主帧和精确载荷门禁；无任意正文、通用 channel 或任意 bounds |
| QueryApp / QuerySopPanel | 输入与查询结果、局部展开、焦点与动画；按 Main 快照显示，移除独立 sopView 写入 |

沿用候选 A 的窄操作接口与不机械更名建议。业务修订、窗口 viewEpoch、快照顺序解决不同问题，不能用一个 sessionId 让勾选或复制取消合法缩放。多任务的任务身份与修订分离；迁移时一次更新所有调用方和 validator，不长期保留两条写入路径。

交叉评审补入以下失效约束。

| 失败或竞态 | 设计要求 |
| --- | --- |
| 非法或无法验证的投影 | 统一读取与订阅结果含 ready / unavailable。清除旧 SOP 正文、图片与复制目标，保留普通查询和受控“重新进入”入口。不能只静默回查询。 |
| sop 指向已结束或不存在任务 | Main 在发布前归一化；sop 必有合法活动任务。正常结束回 query-home，不显示异常读取错误。 |
| 用户返回后旧查询完成 | 可保留结果数据，不能擅自从 home 打开 Top3。 |
| 旧测高、动画回执或缩放晚到 | 按 viewEpoch 和 gesture 拒绝，不能改写当前尺寸。 |
| 复制回复晚于切换任务或步骤 | 按来源任务与修订标记反馈，不把旧成功贴到新步骤。 |
| 关闭确认期间任务变化 | Main 拒绝旧确认，不误关新任务或其他待办。 |
| 在查询结果中关闭非活动待办 | 保留查询结果展示，只缩去该行；不清空普通结果。 |
| 屏幕变小或切换显示器 | 临时钳制实际 bounds，保留用户偏好尺寸。 |
| renderer 回执缺失 | 有界恢复至合法目标并可见反馈；不留透明大窗，也不将 SOP 620px 当查询成功值。 |
| 正式过期、撤权、版本变化 | 待正式 graph/资格接通后按正式合同验证；本合成设计不能替代。 |

多待办采用 Main 内独立任务集合，同名流程使用任务短序号区分。当前合成实现最多保留8条，达到上限明确拒绝新建并保留全部旧进度，禁止静默淘汰。列表不增加窗口宽度，内容过多时按可用高度滚动。
