# 如何操作资料页和权限页

在 `contentIntake: "faq-v2"` 的客服运营工作台里给人设写知识，或给一名已有人员授「客服」/「客服主管」，并新建一个外包坐席。知识库步骤见[如何记下一条人设知识](how-to-operate-desk-knowledge.md)。下面保留权限页。新建坐席不能用 `127.0.0.1:43101` 登录。

字段、岗位和通道见[资料页与权限页](reference-intake-pages.md)。为什么不接独立登录系统，见[为什么岗位和登录是分开的](explanation-intake-pages.md)。

## 前提

- 桌面用显式 FAQ 合成 profile 启动，不是旧的整库替换工作台。
- 操作的人已经能打开工作台。权限页还要求 preload 里有 `dashboardPermissions`。总监和经理用飞书登录后管理权限；外包坐席自己不能打开权限页。
- 真正写入人员和口令时，本机合成库要在跑。只看布局时用下面的预览地址，写入不会落盘。

## 步骤

1. 打开工作台。侧栏点 **知识库**，不要点旧文档里的「内容管理」。这一页是本机人设问答，不是候选表。写一条知识的步骤见[如何记下一条人设知识](how-to-operate-desk-knowledge.md)。

   只看页面、不写库时，在本机打开：

   ```text
   http://127.0.0.1:5173/?role=dashboard&preview=intake
   ```

   权限页把查询改成 `page=permissions`。这个预览里的坐席只存在于当前页面内存。

2. 侧栏点 **权限**，留在 **业务授权**。在「范围内的人员」里选人，选岗位，填写生效时间、失效时间和原因，先点「预览权限」。预览没有写授权。确认无误再点「确认保存权限」。要放弃这次预览，点「返回修改」。

3. 撤销一条已有授权时，点「撤销该权限」，填写撤销原因，再点「确认撤销」。当前姓名不可用时，按授权记录编号、范围和原授权原因核对，不要猜人。

4. 点 **外包坐席**。填写姓名、登录名、密码，岗位保持「客服」，或改成「客服主管」，再点「保存坐席」。登录名只能是 1 到 64 位的字母、数字、下划线或连字符。密码不出现在业务授权表里。

5. 在「已有外包坐席」里，对使用中的一行点「重置」换密码，或点「停用」。停用后该行变为已停用，人还在，只是不能再当使用中的坐席。

## 怎样确认

- 知识库标题是「知识库」。导入后的句子是未生效，不会出现在查询浮层。
- 权限页能看见「业务授权」和「外包坐席」。业务授权里有「范围内的人员」。外包坐席里有「已有外包坐席」。
- Electron 且合成库可用时，`password-accounts.json` 里出现该登录名的 salt 和哈希，没有明文密码。身份服务每次 `POST /password` 都重读这份文件。新坐席不在启动时登记的合成主体里，所以仍返回 401。已登记主体改了哈希，不用重启身份服务。文件读失败返回 503，错误是 `accounts_unavailable`。
- 预览地址里刷新页面后，刚才在预览里新建的坐席消失。这是内存预览，不是漏保存。

## 失败时

- 「账号尚未接入当前运行模式。」：当前不是 `faq-v2`，或从桌面主进程向上四级找不到 `scripts/synthetic-stack/seat-account-runtime.ts`。
- 「账号输入无效。」：意图不是 list、create、reset、disable 这四种形状。list 不能带字段。create 要有姓名、登录名、密码和岗位。reset 只要登录名和密码。disable 只要登录名。这一层不检查登录名格式。
- 「没有可授权的人。」：登录名不匹配 `^[A-Za-z0-9_-]{1,64}$`，姓名为空或长于 256 字，或重置、停用时找不到这个人。
- 「人员没有写入，已停止。」：人没有写进合成库。这和上一句不是同一件事。
- 「口令没有写入，已停止。」：口令文件没有写成。不要把半套人当成可登录账号。
- 「账号没有保存。」：运行脚本的 node 没启动、15 秒超时、标准输出超过 64KiB，或回复无法通过 `seatAccountReply`。
- 预览里点保存看起来成功，但 43101 不能登录：预览本来就不写身份服务。要落盘，改用 Electron 的 faq-v2 工作台。即便落盘，新坐席仍不能从 43101 交换身份。

## 打开本机 SOP 原表

1. 在 Electron 的 faq-v2 工作台里点侧栏 **SOP**。还没有打开文件时，页面写「未接入」。
2. 主进程登记了打开文件的通道时，点「打开原始 SOP 表」，选择不超过 10MB 的六表 xlsx。
3. 读开以后，页面写「原始资料，未发布。坐席流程未切换。」用工作表名切换，表里是行和原文。某一行有图时写「本行有 N 张图，未入库。」

浏览器预览 `preview=intake` 没有这条主进程通道，所以只有「未接入」，没有打开按钮。这张表不调用 `POST /v1/sop/import`，也不改坐席正在用的流程。话术库里的 SOP 页签、概览里的 SOP 使用率，在没有真实目录和步骤事件时仍写「未接入」。

## 看使用情况

1. 点侧栏 **系统同步**。发布行下面是使用情况。
2. 没有使用记录来源时，列表和导出都写「未接入」，不会弹出保存框，也不会写文件。
3. 来源接上以后，问题被抑制的行显示「已脱敏」。「已复制」只表示话术进了输入框。导出前先确认条数：已脱敏和未同意采集的行不进文件，同一条只记一次。

`http://127.0.0.1:5173/?role=dashboard&preview=intake` 或 `127.0.0.1` 上的同一预览可以看见样例数字。打包后的安装包不带这个预览开关。
