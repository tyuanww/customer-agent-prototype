# 如何导入正式资料和配置权限

使用已配置产品服务的客服运营工作台。各页签的职责和数据来源见[资料页与权限页](reference-intake-pages.md)。本机图文导入另见[如何记下一条人设知识](how-to-operate-desk-knowledge.md)。

## 前提

- 用主账号或自己的账号登录工作台。
- 导入、发布或配置权限前，取得目标店铺和来源的相应业务授权。
- 使用目标来源登记的工作簿模板。本机草稿能读取的原始 Excel，不一定满足正式资料的模板要求。

## 导入正式话术

1. 打开侧栏的 **资料审核**，点 **上传资料**，选择要更新的来源，核对店铺和内容域。
2. 选择规范的 Excel 或 CSV 文件。按实际情况填写整理负责人和全部改稿人，再确认参与人声明。
3. 上传并等待解析。查看条目、差异和未通过原因；整批未通过时，修正文件后再修订候选。
4. 在批次表中打开这份资料，先查看原始材料，再进入 **来源确认** 和 **人工质量检查**。逐条暂存判断后提交本轮审核；解析成功不能代替业务审核。
5. 审核通过且具备发布资格后，进入 **发布资料**，填写发布说明，核对范围和有效期，再确认发布整批资料。取消确认会保留当前批次。
6. 发布后，在 **内容库 → 已发布** 和查询窗口选择同一店铺，查询并复制一条核对。复制成功只表示内容进入剪贴板。

响应状态不确定时，先使用原操作恢复入口核对服务端结果。停止等待不会取消已经受理的服务端操作。

当前版本暂不提供新建资料回退入口，须等上一版及影响预览能力正式交付。已有回退操作若结果未明，继续使用原操作恢复入口核对结果。

## 导入本机图文

打开 **内容库 → 本机草稿**，点 **添加话术**。该入口支持 CSV 和 Excel，Excel 预览会列出条目、图片及未导入内容。确认导入后，条目先保存为未生效。

这些条目只在当前电脑保存。要供正式查询使用，按上一节通过资料页审核和发布。正式条目合同当前没有图片字段。

## 配置业务权限

1. 打开 **成员与权限**，在 **成员权限** 中选择范围，点 **新增授权**。选择成员、岗位、生效时间、失效时间并填写原因。
2. 点 **预览权限**，核对将要改变的范围。预览不写授权。
3. 确认后点 **确认保存权限**。要修改预览，点 **返回修改**。
4. 从成员行点 **查看权限**，核对具体权限、范围和有效期，再撤销需要收回的那一条。姓名不可用的记录不会被合并，请展开授权原因并核对记录编号；不要仅凭相同的占位姓名判断是同一人。

## 管理外包坐席

1. 在 **成员与权限** 中打开 **账号管理**。
2. 填写姓名、登录名、密码和岗位，再点 **保存坐席**。登录名是 1 到 64 位字母、数字、下划线或连字符。
3. 为新坐席另行保存业务授权。选择岗位只登记岗位上限，不会自动发放查询权限。
4. 坐席通过与工作台匹配的产品身份服务，用自己的账号和密码登录。该路径不要求先取得飞书 open_id。
5. 需要换密码或停止使用时，在已有坐席行点 **重置** 或 **停用**。停用不删除历史身份和授权记录。

## 本机预览

只看布局时，在本机打开 `http://127.0.0.1:5173/?role=dashboard&preview=intake`。权限页加 `page=permissions`。该预览中的坐席操作只改页面内存，不写身份服务或数据库。

## 读取 SOP 原始表

当前正式资料模式尚未开放 SOP 学习与执行，SOP 页会明确显示状态。图文导入、步骤与分支执行沿原 SOP 任务卡推进；不能用本机草稿导入代替 SOP 发布。
