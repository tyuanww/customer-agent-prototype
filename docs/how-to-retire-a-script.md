# How to 下架一条已发布话术

管理员在「话术库」详情点「下架」，走 `DELETE /v1/content/scripts/{id}`。成功后该条进入 `pending_review` 草稿，**仍留在当前发布目录**。坐席要等下一次整库发布才搜不到这条。

话术库是已发布目录，不在这页上传或改正文。整库替换走[用一张表替换四库之一](how-to-replace-one-library.md)。IPC 见[桌面合同](reference-desktop-contracts.md)。

## Prerequisites

1. 已打开运营工作台，已登录。
2. 角色是**管理员**（合同角色 `owner`）。其它角色会看到「当前角色不能执行这个操作。」
3. 话术库已挂上当前发布（徽章「当前发布已挂载」）。本机目录也可以点下架，但那不是坐席正在搜的租约。
4. 选中的条目有 `scriptVersion`。没有版本号时屏幕写「未接入：没有当前话术版本号。」

没有独立的改正文入口。renderer 没有 `scriptPatch`。

## Steps

1. 侧栏点 **话术库**。域 tab 是产品话术 / 活动话术 / 售前流程 / 售后流程。未登录且没有磁盘目录时空态是「当前发布未挂载」；有磁盘 hydrate 时写「本机目录」，不是坐席检索租约。

2. 选中要下架的那一行。右侧详情显示标题、正文预览、`script_id`、适用平台、有效窗、来源。脚注：「列表来自当前发布。下架进入待审核草稿，发布后才离开当前目录。」

3. 点 **下架**。出现确认条，文案「提交下架审核。坐席要等下一次发布才搜不到这条。」左边「取消」，右边「确认下架」。

4. 点 **确认下架**。进行中按钮禁用，避免连点。成功状态：「已提交下架审核，发布后才离开当前目录。」后面跟 `mutationId`。失败写「服务暂不可用，请重试」或接口中文原因。

5. 该行仍在列表里，生命周期仍是「已发布」。目录不会立刻抽掉它。

## Verification

- 话术库详情仍能打开这条。
- 查询胶囊现在仍能搜到它。
- 下一次在内容管理对同一库发布成功后，这条才离开当前发布。系统同步对应卡应写「本版已更新」。

## Troubleshooting

| 你看到 | 怎么处理 |
| --- | --- |
| 请先选中话术。 | 先点列表里的一行。 |
| 未接入：没有产品会话。 / 未接入：请先登录。 | 先登录。 |
| 当前角色不能执行这个操作。 | 换管理员。 |
| 未接入：没有当前话术版本号。 | 本机索引回退行没有 `scriptVersion`，不能下架。等当前发布挂上。 |
| 确认下架点了没反应 | 进行中会禁用。等状态行出现成功或失败，不要连点。 |
| 下架后坐席立刻搜不到 | 这不是当前行为。坐席要等下次发布。 |
