# 为什么内容库区分已发布与本机草稿

两种内容放在同一个导航入口，方便查找，但用途不同：**已发布** 是团队当前有权使用的话术，**本机草稿** 是这台电脑上的编辑材料。

## 数据归属

已发布内容来自现有正式目录，由 Main 按当前账号、店铺、筛选条件和读取有效期取得。草稿仍由 Main 保存到本机 `desk-knowledge.json`。合并导航不合并存储，也不让查询窗口读取未审核草稿。

团队内容的来源确认、质量检查和发布统一在 **资料审核** 完成。管理员发布后，坐席重新查询取得新版本。本机草稿的“生效”仅用于本机列表，不代表团队可查，也不会自动上传或发布。

## 编辑权限与图片

运营可手动编辑或导入图文草稿。是否具备编辑资格仍由主进程按当前会话判断；隐藏入口不能替代权限校验。

本机 Excel 图片与对应问答一起保存。正式话术合同当前没有图片字段，不能把本机图片保存成功当作服务器图文发布完成；正式 SOP 图文能力沿原任务卡单独接入。
