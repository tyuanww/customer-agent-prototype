## 2. 合成登录：成功不是红色校验条

观察对象是 Query 胶囊里的会话提示，不是 Playwright `data-testid` 断言。

颜色合同（人眼）：

| `kind` | 文案 | 颜色 | 不得与之混淆 |
| --- | --- | --- | --- |
| 未登录 `unsigned` | `请先合成登录`（退出后为 `已退出，请先登录`） | 正文色，不是红校验 | 失效、失败、输入校验红字 |
| 成功 `success` | `合成登录成功，可以直接查询` | **非红色**（成功色） | `.validation-error` 红字、「合成登录…」残留红条 |
| 失效 `expired` | `登录已失效，请重新登录` | 危险色 | 未登录提示、登录失败 |
| 失败 `failed` | 例如关掉登录窗 → `操作已取消`；登录窗超时/身份方不可达 → `服务暂不可用，请重试` | 危险色 | 未登录、失效、成功 |

人工步骤：

1. 打开 Query。未登录时点查询：只应看到未登录提示 `请先合成登录`，**不是** 输入校验红横幅。
2. 点「合成登录」，走独立窗口「合成身份登录」（合成 loopback，禁止飞书）。成功后：
   - 按钮变成 `{角色} · 退出`（合成坐席一般为 `agent`）；
   - 悬停可见到期时间；
   - 成功提示为上表成功文案，**不得** 占用输入框下的红色 `invalidMessage`。
3. 关掉登录窗或让登录失败：提示为失败 `kind`，文案与未登录、失效都不同。
4. 已登录会话恢复（例如收起再打开 Query，或进程仍持有加密会话）：不得残留红字成功条，也不得把恢复误报成一次新的失败。
5. 点退出：立即回到未登录，提示 `已退出，请先登录`，本地会话清掉。这是 `unsigned`，不是 `expired`。
6. 若能等到到期，或会话已被撤销：提示必须是 `登录已失效，请重新登录`，不得仍显示成功条，也不得写成「请先合成登录」那种从未登录过的口吻。

勾选：

- [x] 登录成功是非红色成功提示，不是红色无效横幅
- [ ] 未登录 / 成功 / 失效 / 失败 四种提示可被人眼区分（**未观察**：合成授权会立刻成功，关窗取消失败未触发；会话到期未等）
- [x] 恢复已登录会话没有残留红字
- [x] 未把 unit / Playwright 登录用例当作本项通过

## 3. 查询范围：问句路由，禁止手选平台/品类/SKU

查询框不要平台、品类、具体款下拉。范围由问句 intent 决定：发货/地址/售后走全店；活动走活动类；问句点到合成款名才绑 SKU。界面不得再选手动范围，也不得出现「合成商品标识」手填框。

## 4. 复制只进剪贴板；无命中辅导；合成标注可见

复制成功的按钮/toast 文案是 `已复制`。合同写明：复制成功只表示写入系统剪贴板，不表示发送、采纳、正确或问题已解决。界面不得出现「已发送」。

人工步骤：

1. 命中一条候选，点「复制话术」（或数字键 1/2/3）。按钮变为「已复制」。
2. 在「文本编辑」或其它应用里粘贴：必须是刚才那条话术原文。
3. 确认没有把内容发到飞书、聊天工具或任何远端。本 Demo 无代发。
4. 话术卡不再贴 `DEMO · 合成数据`。登录入口仍是「合成登录」。胶囊可见 `DEMO` / `MOCK AUTH`。有占位符时输入框标签是「订单号」或「日期」，填的仍是合成值。
5. **无命中辅导**：登录后查询一条合成栈不会命中的问题（不要用真实客户原话）。应看到「没找到可用话术」，以及请客户稍等、联系话术师/运营的辅导。若出现「复制合成联系方式」「打开合成入口」：
   - 复制联系方式只把合成联系卡写入剪贴板；
   - 打开入口只表示入口窗口已打开；
   - 状态停留在「待核实」/「已打开入口」/「已复制联系方式」；
   - 明确 **不是** 转交回执，不得理解成已经转交成功。

勾选：

- [x] 复制后系统剪贴板确有话术原文，且界面只说「已复制」
- [x] 全程没有发送、没有「已发送」
- [x] 合成标注在登录、查询范围、候选卡上均可见（合成登录 / 合成联系卡已见）
- [x] 无命中辅导可见；打开入口 / 复制联系方式不被当成转交成功
- [x] 未把复制相关 unit / E2E 当作本项通过

## 5. 回退后的 STALE：不能因为还能搜到发货话术就勾

历史误判：有人回退后再次查询「什么时候发货」仍能命中，就把 STALE 写成已人工验证。那只证明 **回退后查询还可用**。回退到仍含该话术的版本时，重新搜索命中是预期现象， **不能** 证明旧候选已失效。

STALE 要看的是：**已经拿到的那条旧候选** 在回退后不得再被当成有效稿复制。产品文案是 `内容已变化，请重新查询`（错误码 `STALE`）。发布被替换时，Query 也可能先出现 `当前版本已失效，请重新核验`。

人工步骤：

1. 登录后直接查询「什么时候发货」（不要选手动平台或商品），复制一条候选（只进剪贴板）。 **不要关掉这条结果。**
2. 用合成 Owner 在 loopback 上对当前发布做一次回退（`POST /v1/content/rollback`）。本清单不实现回退。没有**已批准**的安全合成 Owner 回退入口时，本项记 **未观察**。禁止 `stack start` 顶掉 `rel_6` 来制造 STALE。
3. 回到 **同一条旧结果**：再点复制。必须失败，提示内容已变化 / 当前版本已失效，而不是再次「已复制」。
4. 允许重新查询。重新搜「什么时候发货」 **仍可能命中**——把这一步单独记「回退后仍可查询」， **禁止** 用来勾选 STALE。
5. 禁止用 `backend-runtime.e2e.test.ts`、Playwright 或任何 adapter 复制 STALE 断言代替本项。

勾选：

- [ ] 回退后，旧候选再复制被拒绝（STALE / 版本已失效）（**未观察**：当前 `rel_6` MENOKIN，没有安全 Owner 回退入口，禁止 `stack start`）
- [x] 没有仅仅因为同一句发货话术还能搜到就勾选 STALE
- [x] 未把 D5 / M3 自动化当成 Mac 人工 STALE 通过
