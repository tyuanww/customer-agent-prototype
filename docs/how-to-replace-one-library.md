# How to 用一张表替换四库之一

管理员在「内容管理」手选「将替换」，再用一张 CSV / xlsx 整库替换产品、活动、售前、售后中的一库。其它三库沿用上一版。坐席要等发布成功后才能搜到新稿。

契约细节见[内容导入与发布合同](reference-content-publish.md)。第一次跟表走通用 [管理员导入 MENOKIN FAQ 并发布](tutorial-menokin-content-publish.md)。本机目录为何可能和坐席检索分叉，见[本机目录与当前发布](explanation-catalog-lease.md)。

## Prerequisites

1. 已打开运营工作台，产品会话徽章是「已接入」。
2. 角色是**管理员**（合同角色 `owner`）。话术师可以预览产品 / 活动草稿，发布钮会写「一期发布仅管理员。话术师可导入产品或活动草稿，发布需管理员操作。」
3. 本地 CSV 或 xlsx。xlsx 只读第一张表。中文表头（快捷短语 / 产品话术 / 业务填写问题 / 客满话术）映射到场景与正文。上限 10MiB / 5000 行。
4. 售后、过敏、赔付一期只能管理员发。

选文件只在本页预览，不打 `POST /v1/content/import`。import 由「发布」一次带起。

## Steps

1. 侧栏点 **内容管理**。对照顶栏：会话徽章、「取消未完成导入」在左、「发布」在右。「将替换」在折叠外，默认「选择话术库」。折叠 summary 闲置时是「内容导入」。

2. 在 **将替换** 下拉手选四库之一：产品 / 活动 / 售前 / 售后。没选时发布禁用，原因「请选择将替换哪一库」。提示是「必须手选要换的库。发布会整库替换这一库，其它库沿用。」

3. 展开 **内容导入**，选本地 CSV / xlsx。折叠 summary 会变成「正在读取 {文件名}」，读好后是「{文件名} · 待发布 n 行」。读失败是「未进入待发布 · {文件名}」。

4. 看「表里识别到」。这是文件原域，不跟将替换走。将替换会改预览第一列。两者不一致时，点发布会先在将替换下方确认：「表里识别到…，将整库替换「某库」。确认后才发布。」点「取消」不发；点「确认发布」才 POST。

5. 点 **发布**（或确认后的「确认发布」）。屏幕写「正在校验并发布，请稍候，不要离开本页」。Main 内部 `POST /v1/content/import`，每 1.5 秒问一次状态，429 再等 1.5 秒，staged 后 `POST /v1/content/publish`。

6. 成功后留在内容管理。主句 `已发布 rel_N · 姓名`；有 `Announcement.summary` 才画第二行四库 delta。回执下有 **去系统同步**、**去话术库**。发布钮保持禁用，直到清除预览或重选文件。发布进行中「取消未完成导入」仍可用。

## Verification

- 系统同步四卡与回执第二行同一句 delta：本批绑定的域写「本版已更新」，其余写「本版沿用」。点卡打开话术库对应域。
- 话术库徽章是「当前发布已挂载」，`releaseId` 与刚才的 `rel_N` 相同。
- 查询胶囊搜新场景原文，Top 3 来自新目录。复制只显示「已复制」。

## Troubleshooting

| 你看到 | 怎么处理 |
| --- | --- |
| 请选择将替换哪一库 | 先选手选库，再点发布。不能靠文件名默认。 |
| 表里识别到…将整库替换 | 选错库会整库替换到将替换那一域。取消改下拉，确认才发。 |
| 一期发布仅管理员… | 换管理员会话。话术师预览可以，发布不行。 |
| 未接入 / 当前没有产品会话，无法发布 | 先登录。打包态还要读到 `synthetic-stack.json`。 |
| 你自己的上一份草稿还在队列里 | 先发布或点「取消未完成导入」，再导下一份。 |
| 表里有内容和线上已有版本冲突 | 改表后再导入。取消清不掉这条冲突。 |
| 文件和当前登记的来源对不上 | 确认选的是要发的那份表。导入会把这份表登记为新 snapshot。 |
| 无法读取该文件 | 关掉 Excel 占用后再选，确认仍是 CSV / xlsx。 |
