## 新包和测试入口

使用 `pnpm package:mac:local` 生成 Universal DMG/ZIP，保留原包到 `release/preserved-before-ui-25c0bd5-20261009/`。实际只读挂载新 DMG，复制到本任务的独立安装目录后卸载；没有覆盖系统 Applications 或用户安装。

[产物摘要](installed-artifact.json)绑定新包、可执行文件和 app.asar；安装副本与构建副本字节相同。打包日志到达内置后验通过，首次异步调用的退出码未被保留；另行执行包后验通过，并由后续实际安装态测试消费产物，没有仅凭日志末行认定可用。[挂载与复制记录](package-install.json)、[旧包保留位置](preserved-artifacts.json)均可复核。

此前只有上传用例支持安装路径，其余用例仍启动 `out/main/index.js`。本轮把已有安装选择、独立 profile、身份核验及失败清理收敛到 `tests/support/intake-electron.ts`，接入上传、权限、四域、回退和同名店铺五个测试文件。安装路径为空、无效或相对路径时拒绝，不回退开发构建；profile 使用 `0600`、`wx`，开发 origin 故意不可达。初始化失败关闭自有 Electron，成功后仍由原测试清理。业务断言和原窗口尺寸门未改。

[八份安装身份](installed-identities.json)均确认 `isPackaged=true`、同一个新 executable/app.asar、版本 0.3.26 与各自全新 userData；运行后核实八个 userData 均不存在。PG 与 HTTP 继续使用现有一次性合成宿主、35 段迁移及用途受限池。CSV 日志中的自有 PG 和桌面目录也已核实清理；其余用例的原 `finally` 完成宿主关闭。
