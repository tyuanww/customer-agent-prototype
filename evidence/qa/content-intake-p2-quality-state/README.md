## 实现与边界

- API 质量模块提供 `freezeQuality` / `quality` / `checkQuality`；每次新操作重验 review 权限、完整候选材料、来源/base/当前状态，事务继续共用内容首锁和永久回执。
- `0023_intake_quality` 追加封闭计划/检查轮次存储。每轮保存完整逐条结果、实际操作者与事实版本，数据库从结果投影状态；冻结在检查之前，计划和检查不可修改/删除。旧 22 段迁移与 upstream 均未改变，应用 ACL 清单仍为 223 条、摘要不变。
- 按冻结 ID/hash 验证精确集合；扩样必须原样包含初样。500 条以内全检；501 条普通稿初样 100 / 扩样 151，2% / 5% 临界经过实测。任一缺陷最终要求整批修订；新候选不能借用旧证据。
- 关键稿复用同人身份与贡献者回避检查，5,000 条启用项全检。缺行继承、显式停用和整份材料绑定沿用前切片。
- `passed` 只是该材料的质量结果，不替代组织审批或负责人承接，不签发票据/release，不改变原 `ready` 含义。原 operation 重放只恢复历史回执，不证明当前发布资格。
