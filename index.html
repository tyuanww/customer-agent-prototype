产品

两套表面，各做一件事

浮窗给接待用，工作台给运营用。查询只走当前已发布的目录，不生成新话术，也不代发到接待窗口。

坐席浮窗

平时桌面上只剩狐狸头。需要时展开成玻璃查询胶囊。

狐狸头常驻

约 88px 透明狐狸置顶，跳过任务栏。点狐狸或按 Ctrl+Shift+Space（Mac 为 ⌘⇧空格）打开查询胶囊。Esc 或再点狐狸收回。

登录后再查当前发布

未登录占位「登录后查询话术」。点登录走公司飞书。登录后只检索当前已发布目录，给出 Top 3 原文。点「复制话术」或按 1 / 2 / 3，人在环，不代发。

话术不准与过敏 SOP

结果卡可报「话术不准」。过敏问句会出现「打开过敏售后流程」，坐席只读预览，不建单。

智能检索只重排已有话术

胶囊右侧开关默认开：规划检索式并重排已有话术 id，不生成、不改写正文。关掉则走本地检索。

运营工作台

另开一扇「客服运营工作台」。白底、紫锚点，五个模块。

五个模块

管理概览、话术库、SOP、内容管理、系统同步。从查询胶囊的工作台图标、狐狸右键或系统托盘打开。

话术库读当前发布

产品 / 活动 / 售前 / 售后四域。搜索标题、场景、正文，可导出 CSV。管理员下架后这条仍可见，下次发布才离开目录。

整库替换再发布

内容管理导入 CSV 或 xlsx，进入待发布。一期仅管理员点发布后，坐席才能搜到新内容。话术师可以导表，不能发布。

SOP 与系统同步

SOP 是独立树，删除仅管理员；坐席过敏窗只读。系统同步用一张 rel_N 四卡标「本版已更新 / 本版沿用」。软件目录无自动更新。

安装

装完从开始菜单打开

  1. 下载 Windows 安装包。文件名带 UNSIGNED，表示未代码签名。
  2. 若 SmartScreen 弹出「Windows 已保护你的电脑」，选「更多信息」，再选「仍要运行」。
  3. 当前公开的 0.3.24 会直接装进当前用户目录，进度条走完即可。仓库已改成中文安装向导（许可、路径、快捷方式），随下一版 Windows 包发布。
  4. 从开始菜单打开「客服话术浮窗 Demo」。桌面也会有快捷方式。
  5. 下载不等于开通账号。登录仍用公司飞书。坐席查当前发布，话术师导表，管理员发布。
